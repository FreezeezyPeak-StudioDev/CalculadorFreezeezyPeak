## English

**CalculadorFreezeezyPeak** - x86-64 Assembly Calculator

- Fully functional UI
- First serious ASM project
- No frameworks, pure ASM power

### Setup
- Download FASM from [flatassembler.net](http://flatassembler.net)
- Compile: `fasm calculadora.asm calculadora.exe`
- Run: `calculadora.exe`
