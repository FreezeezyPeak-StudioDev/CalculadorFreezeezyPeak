# CalculadorFreezeezyPeak

## English
CalculadorFreezeezyPeak - x86-64 Assembly Calculator. Fully functional UI. First serious ASM project.

## Español
CalculadorFreezeezyPeak - Calculadora en Ensamblador x86-64. Interfaz completamente funcional. Primer proyecto serio en ASM.

---

## Setup
- Download FASM from [flatassembler.net](http://flatassembler.net)
- Compile: `fasm calculadora.asm calculadora.exe`
- Run: `calculadora.exe`
